# VITALS website

The public website for **VITALS** — Team TETHER, NASA HUNCH 2026–27, South Texas ISD Science Academy.

Live: https://blackphenixlord.github.io/vitals/

A plain HTML copy of the Wix site (https://joshuacollado636.wixsite.com/vitals), plus the PDR print files:

- `downloads/VITALS-trifold-board.pdf` — the full 36 × 48 in display board
- `downloads/VITALS-trifold-panels.pdf` — the board as three separate panels
- `downloads/VITALS-brochure.pdf` — the tri-fold brochure

Edit `index.html` and push; GitHub Pages republishes it in about a minute. No build step.
Fonts: Tektur and IBM Plex Sans (SIL Open Font License), in `fonts/`.
